# SkySync Scripts

These scripts were initially created to migrated from Box to both OneDrive and Teams (shared Documents/General) in the general channel. Technically, the migration is using SPO connections and then just migrating to the library behind the Files tab.  These scripts map a users top level folders to a destination in SPO or ODB.  All migration jobs are moved to a "Box Migration" folder. We have only done one migration with SkySync at this point so these scripts will likely need to be made more generalized as part of future engagements.
