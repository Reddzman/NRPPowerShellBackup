# Archival Scripts

Archival scripts are often very specific to the solution that content is being archived from.  For that reason, these scripts are less general and more focused on archiving the content generated by users leveraging a solution.  Although they are solution specific the scripts in this directory have a lot of great sample code for accomplishing different things.  Each script should have an outline of the useful features that can be taken from these samples.

## Cat.PnP-ArchiveItemsToSQL.ps1

This script script is designed to archive items from the AZDPS PAR system to a SQL Database to avoid threshold limits.  It looks up settings in a settings list on the PAR site to determine the Database/Table information and the active time period for list items.  Archived items will be in a ```Complete```  status and will not have been modified in the past ```X months based on the setting```. The decision was made by AZDPS that the request and attachments will be printed to PDF and stored in another system (ViewCenter) to meet retention requirements.  Therefore, SharePoint is not the source of record and archived requests will be copied to SQL for reporting purposes. All attachments will be deleted. Currently built for SP13 PnP PowerShell.

Here are some of the neat features of this script:

* Gets SQL connection & retention settings from a custom SharePoint list built for the solution
* Uses CAML queries to only return items that require archival
* Builds dynamic SQL query to write columns data to SQL based on a CSV file
* Writes SharePoint Custom list data to SQL Table
* Confirms existence of SharePoint item in SQL prior to proceeding
* Deletes item, associated documents, and sub list data and sends them to the SP Recycle bin (Parameter)
* Loops through array to perform find and replace on SP Column names to match to SQL column names
* Loops through hash table to find and replace characters not handled by Invoke-SQLCMD Variables (=, ', etc.)
